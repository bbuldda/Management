# 남지국민체육센터 스마트 자산 관리 시스템

스마트폰 카메라로 자산 바코드를 스캔하고, 실물 사진을 촬영·저장하여 현장에서 물품을 쉽고 빠르게 찾을 수 있는 웹 애플리케이션입니다.

## 🚀 주요 기능
- **실시간 바코드 스캔**: 스마트폰 카메라 및 웹캠을 활용한 바코드 인식
- **실물 사진 저장**: 카메라로 현장 자산을 직접 촬영해 LocalStorage에 압축 저장
- **상세 정보 및 이미지 조회**: 바코드로 즉시 자산 정보와 실물 사진 대조
- **35건 자산 기본 탑재**: 남지국민체육센터 초기 자산 데이터 자동 세팅
- **CSV 내보내기/가져오기**: 엑셀 연동 데이터 관리 지원

## 🌐 GitHub Pages 배포 방법
1. 이 저장소의 **Settings** 탭으로 이동합니다.
2. 좌측 메뉴에서 **Pages**를 선택합니다.
3. **Build and deployment**의 Branch를 `main` (또는 `master`)로 설정하고 **Save**를 누릅니다.
4. 잠시 후 상단에 생성되는 `https://[계정명].github.io/[저장소명]/` 주소로 스마트폰(크롬 브라우저)에서 접속해 사용하세요.
